# Presentation

Turn figures into a deck an owner can present without being caught out.

## Establish first

1. **Audience** — board, doctors, investors, staff. It changes what leads.
2. **Length** — how many slides, how many minutes.
3. **The one message** they should leave with.

## Outline template

1. **Title** — the message, not "Monthly Report".
2. **Situation** — three figures that set the scene.
3. **What moved** — the two or three changes that matter, one per slide, each with a chart idea.
4. **Why** — the driver behind each change, stated as a cause, not a coincidence.
5. **What we are doing** — actions already taken.
6. **What we need** — the ask, if there is one.
7. **Appendix** — the tables behind the charts.

## Rules

- **One idea per slide.** If a slide has two, split it.
- **Every number comes from the data.** No placeholder figures.
- **Say what you do not know.** If a figure is missing, say so on the slide rather than omit the
  slide.
- Give each slide a **speaker note** in one or two sentences.

## Never

- Design slides in code unless asked; give the outline and the chart type.
- Use a comparison that is not like-for-like (e.g. a part-month against a full month).
